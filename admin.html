⚡ Conexão com Supabase (Backend Serverless)

Conecte seu banco de dados PostgreSQL na nuvem para ter sincronização em tempo real entre todos os dispositivos. Se preferir, o sistema continua funcionando perfeitamente em modo Local / Cache sem necessidade de credenciais.

📜 Como criar as tabelas no Supabase:

  1. Acesse seu painel no Supabase Dashboard e abra seu projeto.
  2. Vá em SQL Editor no menu lateral esquerdo.
  3. Clique no botão abaixo para copiar o script pronto e cole-o no SQL Editor do Supabase, depois clique em Run.
